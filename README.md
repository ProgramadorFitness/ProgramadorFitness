<h2>🏗️ Engineering Principles</h2>

<p>
I try to make deliberate technical decisions rather than adding complexity for its own sake.
</p>

<ul>
  <li><strong>Keep systems understandable.</strong></li>
  <li><strong>Prefer simple solutions over unnecessary complexity.</strong></li>
  <li><strong>Design for change.</strong></li>
  <li><strong>Separate responsibilities.</strong></li>
  <li><strong>Treat security as part of architecture.</strong></li>
  <li><strong>Make business requirements visible in the design.</strong></li>
  <li><strong>Document important technical decisions.</strong></li>
  <li><strong>Automate repetitive processes.</strong></li>
  <li><strong>Test critical behavior.</strong></li>
  <li><strong>Optimize when there is a measurable reason to optimize.</strong></li>
</ul>

<blockquote>
  <strong>I don't try to use the most technologies.</strong><br />
  I try to use the right technologies for the problem.
</blockquote>
